# Archived website drafts

Moved here 2026-10-02, when `index.html` was rewritten to reflect the SFV → Kinvergence
repositioning. Each of these predates that refactoring and carries FVF-era content that needed a
full de-instancing pass rather than incremental fixing:

- **`index1a.html`**, **`index3.html`** — unmerged drafts of a planned website redesign (late 2025 /
  early 2026), both still containing a dedicated "The Family Ventures Framework" section — general
  framework material that is now Kinvergence's, not SFV's — plus unverified cumulative stats (5.5+
  years, 285+ heartbeats, 65+ Demo Days) that were checked against `sfv-timeline.md` and found
  unreliable.
- **`family-ventures-framework-2.html`** — a fuller mockup of the same "Family Ventures Framework"
  concept, pre-dating the Kinvergence name entirely.

`index1.html`, `index2.html`, and `family-ventures-framework-1.html` were removed outright in an
earlier pass (2026-08-28) rather than archived — see `advance-sfv-2.md`'s Progress Log. These three
are kept instead because they carry narrative and design choices (member cards, impact stats
framing) that may still be worth mining for copy.
